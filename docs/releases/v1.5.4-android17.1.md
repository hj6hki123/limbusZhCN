# v1.5.4 Android 17 登入相容修復（測試版）

修復 Samsung SM-S9180 / Android 17 診斷中，Google 登入停在黑畫面，以及 Apple
登入無法開啟瀏覽器的兩個相容性問題。保留 1.5.3 的啟動回呼修復。

## 修正內容

- Google：同程序的服務連線改用執行時的四參數直接回呼，保留 GMS 服務包裝與原始
  session Binder，避免把 Java 包裝物件寫入 Parcel 後遺失服務。
- Apple/Firebase：支援 Firebase 先查詢無網址 ACTION_VIEW 的瀏覽器探測流程，並僅為
  Firebase HTTPS `/__/auth/handler` 開放宿主瀏覽器。其他宿主 App 隔離維持原有策略。
- 瀏覽器啟動只攜帶登入網址和實際瀏覽器元件，不轉送外部 extras、URI 授權或 clip data。

## 安裝與簽名變更

下載 `LimbusZhCN-v1.5.4-android17.apk`，安裝後開啟「邊獄漢化 Android 17 修復版」。
包名為 `com.example.limbuszhcn.android17`，版本 1.5.4 / code 10，可與上游原版並存。

**這次使用新的社群簽名，無法覆蓋安裝 v1.5.3 Android 17 測試版。**
若仍保留舊測試版，請先在其「高級設定」匯出需要保留的遊戲資源，再自行決定是否
卸載重裝。**卸載會刪除該測試版的容器資料和登入狀態**；資源匯出不包含帳號、存檔或
登入憑據。已卸載舊測試版者可直接安裝。後續社群版本會沿用本次新簽名。
